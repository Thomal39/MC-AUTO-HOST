Herunterladen. Starten. Spielen.

App herunterladen

Lade die Windows-EXE über den Button oben herunter und starte MC-AUTO-HOST-Setup.exe.

Server erstellen

Wähle einen Namen, Software, Minecraft-Version und RAM. Beim ersten Start werden Serverdateien geladen.

Adresse teilen

Die App zeigt die passende Adresse für deinen PC und für andere Geräte im selben WLAN an.

Auf demselben PC localhost:<Server-Port>
Auf einem Gerät im selben WLAN <LAN-IP des PCs>:<Server-Port>

Wenn andere Geräte nicht beitreten können, erlaube Java in der Windows-Firewall für private Netzwerke. Für dieses lokale Setup brauchst du keine Router-Portfreigabe.
